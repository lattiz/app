# Biblioteca de diseños Stitch

Candidatos de diseño traídos de Google Stitch, versionados como datos (no código). Una carpeta por
candidato: `<giro>/<id>/` con `candidate.json` (la bandera `status`), `design.md`, `screenshot.png` y,
tras `lattiz design harvest`, `harvest.json`. `../index.json` se genera con `lattiz design reindex`.

Guía y reglas: `docs/design-stitch-flow.md`. Nunca se copian imágenes de Stitch a esta carpeta como
activos de producción; la captura es solo referencia visual.
